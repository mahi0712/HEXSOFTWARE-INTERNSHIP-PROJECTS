# 🍽️ Restaurant Menu + Ordering Page

**HexSoftwares Internship — Web Development — Project 01**

## 📋 About
A frontend-only restaurant ordering website built with **HTML, CSS, and JavaScript**. Users can browse a live menu, add items to a cart, update quantities, remove items, and see a running total — all without a backend (as per task requirements).

## ✨ Features
- Live menu display with images, names, descriptions, and prices
- "Add to Cart" button on every menu item
- Cart section with quantity increase/decrease controls
- Remove item from cart
- Auto-calculated cart total
- Simple checkout flow (frontend simulation)
- Fully responsive layout

## 🗂️ File Structure
```
proj1_web_restaurant/
├── index.html      # Page structure
├── style.css        # Styling
├── script.js         # Cart logic (add/update/remove, totals)
└── README.md          # This file
```

## 🚀 How to Run
1. Download/clone this folder.
2. Open `index.html` directly in any browser (Chrome, Edge, Firefox).
3. No server or installation needed — it's pure HTML/CSS/JS.

## 🛠️ Tech Used
- HTML5
- CSS3 (Flexbox + Grid)
- Vanilla JavaScript (DOM manipulation, event delegation)
