About This Blog

A little context on what this project is and how it's built.

What is this?

This is a simple blog website built as Project 01 for the Hex Softwares internship. It demonstrates a basic multi-page site structure with linked pages, a working blog form, and client-side data storage.

Built with

  • HTML5 for structure and semantic pages
  • CSS3 for layout, responsiveness, and styling
  • Vanilla JavaScript for interactivity
  • Browser localStorage for temporary post data

Pages

  • Home — shows the 3 latest posts
  • Blog Posts — write and view all posts
  • About — this page
  • Contact — a validated contact form

Learning goal

The goal of this task is to practice basic website structure, page linking through navigation, and simple form handling.
