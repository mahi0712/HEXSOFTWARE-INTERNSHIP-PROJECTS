# 📝 HexBlog — A Blog That Doesn't Need a Backend (Yet)

> "It's not a real project until it has a README with too many emojis." — every developer, ever

Welcome to **HexBlog** — a simple, snappy blog website built as Project 01 for the **Hex Softwares Internship**. No servers, no databases, no drama. Just HTML, CSS, JavaScript, and your browser's `localStorage` quietly doing all the heavy lifting in the background like an underpaid intern (relatable, honestly).

---

## 🎯 What Is This Thing?

A 4-page blog where you can:
- 📰 Read the latest posts on the **Home** page
- ✍️ Write and publish new posts on the **Blog** page
- 🙋 Learn about the project on the **About** page
- 📬 Send a (fake, very fake) message on the **Contact** page

Everything you publish lives in your browser's `localStorage`. Refresh the page? Still there. Close the tab and come back tomorrow? Still there. Clear your browser data? ...RIP, your posts. 💀

---

## 🗂️ Project Structure

```
project1-blog/
├── index.html      → Home page (shows latest 3 posts)
├── blog.html        → Write + view all posts
├── about.html        → The "who, what, why" page
├── contact.html        → A form that goes absolutely nowhere (on purpose)
├── style.css              → Makes it look less like 1998
└── script.js                 → The brains of the operation 🧠
```

---

## 🚀 How to Run It (No, You Don't Need Node.js)

1. Download / copy all the files into one folder
2. Keep the file names **exactly** as they are (JavaScript is petty about typos)
3. Double-click `index.html`
4. Congratulations, you're now a full-stack developer*

## ✨ Features That Actually Work

- ✅ Fully responsive — looks good on your phone, your laptop, and that one ancient tablet you forgot you owned
- ✅ Form validation that actually yells at you (nicely) if you forget a title
- ✅ A mobile hamburger menu that opens and closes like it's supposed to
- ✅ Zero backend, zero downtime, zero server bills

## 🐛 Known "Features" (a.k.a. Limitations)

- Posts are only visible on **your** browser — not exactly going viral
- Clearing browser cache = clearing your entire blogging career
- The Contact form sends messages into the void (a polite, well-designed void)
